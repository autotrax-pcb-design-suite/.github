## PCB Design Overview

AutoTRAX is an integrated electronic design package that unites schematic capture and PCB layout within a single-document workflow, so an entire project lives in one connected space. This unified model removes the friction of juggling separate files and keeps schematic and board perfectly in step.

Designers place and wire components on the schematic, then move to the layout where the same connectivity drives placement and routing. An autorouter accelerates completing the nets, while manual tools remain available for the traces that demand deliberate attention and careful control.

The environment adds rich 3D visualization, presenting the populated board and even mechanical context so form and fit can be assessed alongside function. With standard manufacturing exports rounding out the flow, AutoTRAX carries a design from first symbol to fabrication data without leaving its unified home.

## Getting Started Playbook

Create a new AutoTRAX project and begin on the schematic sheet, placing components from the libraries and wiring them into your circuit. Because the project is unified, the connectivity you define immediately informs the layout side without any manual netlist transfer.

Switch to the PCB view, define the board outline, and place the footprints in a sensible arrangement. Route the connections using the autorouter and manual tools, run the design checks to confirm the board obeys your rules, review it in the 3D visualization, and export the Gerber and drill files when everything is ready for fabrication.
